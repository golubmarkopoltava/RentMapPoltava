Об’єкти «у переліку» Prozorro: чи справді вони вільні

36 об’єктів мають у Prozorro статус «включено до переліку». Звірка з переліком договорів міста показує: для 31 з них є договір на ту саму адресу й площу, ще 4 — під питанням. Оцінка недоотриманого доходу (площа × медіана аналогів × 12) рахується лише там, де договору немає в жодному джерелі.

Чотири джерела — жодного спільного ключа

Джерела рахують різне (об’єкти, договори, адреси), але саме тому їх треба зводити: у документах міста немає ідентифікатора Prozorro, в інвентарі — лише адреси.

Як зв’язалися дані

Об’єкти орендодавця в Prozorro, яких немає в наборі міста

Орендодавець — Управління майном комунальної власності міста (ЄДРПОУ 13967034), форма власності — комунальна. Статус «неактивний» може означати виключення з переліку.

Дефекти даних

Розбіжності площі: Prozorro ↔ перелік договорів міста

Адреса збігається, площа — ні. Від площі залежить орендна плата, тож кожен випадок варто звірити з технічною документацією. Частина — інше приміщення за тією самою адресою.

Як працює рішення

  1. Перелік P3-01 (553 ocid) збагачується через відкритий API Prozorro.Продажі: адреса, площа, координати, статус, балансоутримувач, орендодавець.
  2. Для кожного об’єкта завантажуються всі пов’язані орендні аукціони (за полем registryObjectId).
  3. Перелік договорів, інвентар і перелік приватизації міста зв’язуються з об’єктами за нормалізованою адресою (+ площа). Окремо показано, скільки записів зв’язано автоматично і скільки потребують ручної перевірки.
  4. Індикатори рахуються за правилами з порогами; кожен сигнал має посилання на лот або рядок джерела.
  5. Оновлення: скрипт update.py повторює збагачення з API та перебудовує цей файл — без змін у коді.
