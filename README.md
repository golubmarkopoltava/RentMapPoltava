# RentMapPoltava

**Прозоре управління комунальним майном Полтавської громади.** Poltava Open Data Hackathon 1.0, трек 3.

**Демо:** https://golubmarkopoltava.github.io/RentMapPoltava/

Одна картина орендного портфеля громади: де вільні приміщення, за скільки здане майно, які аукціони мають ознаки ризику і де розходяться дані міста та Prozorro.Продажі.

## Проблема і користувачі
Відкритий набір міста (P3-01, listProzorroSales) містить лише 3 поля (ocid, назва, url) для 553 об’єктів. Адреси, площі, статуси, аукціони, договори та облік розкидані по Prozorro.Продажі та PDF-документах без спільного ключа.

| Користувач | Що отримує |
|---|---|
| Підприємець | Карту вільних приміщень з фільтрами і переходом до лота |
| Посадовець Управління майном | Портфель, довго вільні об’єкти, низькі ставки, список для аналізу (експорт) |
| Фінансовий орган | Ставки грн/м², розбіжності статусів, оцінку недоотриманого доходу (лише де договору немає в жодному джерелі) |
| Уповноважена особа з питань запобігання корупції | Список аукціонів з ознаками ризику та поясненням кожної ознаки |
| Депутат | Довідку про об’єкт на одну сторінку (друк) |
| Журналіст, ГО | Історію об’єкта в одному місці; дефекти даних |

## Додатково (з концепції команди POLTAVA PROPERTY)
- **Статус використання з двох джерел** замість копіювання статусу Prozorro: 31 з 36 об’єктів «у переліку» мають договір у переліку міста.
- **Помічник** — запит звичайною мовою → фільтри (детерміновані правила, без генеративного ШІ; показує лише записи з даних).
- **Календар договорів** (60 / 90 / 180 днів, строк минув) з експортом.
- **Розбіжності площі** між Prozorro і переліком міста (41 об’єкт).
- **Порівняння** до 3 об’єктів; **орієнтовний калькулятор** (медіана аналогів, з позначкою «не оцінка»).
- **Картка:** джерело біля полів, «немає підтверджених даних» замість нуля, QR-код, обране (зберігається в браузері).
- **Повідомити про проблему** (демонстрація): формує текст звернення; облік і статуси — наступний етап.

## Дані та API
- P3-01 — перелік об’єктів оренди в Prozorro.Продажі (553 записи): `data/p3-01_listProzorroSales.csv`
- Prozorro.Продажі, відкритий API: `POST https://procedure.prozorro.sale/api/search/registry` (об’єкти), `POST https://procedure.prozorro.sale/api/search/procedures` (аукціони). Фільтр `registryObjectId` IN [ocid…]; об’єкти орендодавця — `relatedOrganizations.sellingEntity.identifier.id = 13967034`. Отримано 2026-11-19 09:55 UTC.
- Перелік переданих в оренду об’єктів станом на 30.06.2026 (PDF Управління майном, 554 договори) → `data/leases.json` (фізичні особи знеособлені)
- Перелік нежитлових об’єктів станом на 01.01.2026 (PDF, 459 адрес) → `data/inventory.txt`
- Перелік об’єктів приватизації 2026 (рішення 74 і 81 сесій) — у `scripts/build.py`
- Звіт Управління майном за І півріччя 2026
- Завершені аукціони малої приватизації Управління на Prozorro.Продажі (30 продажів 2024–2026) → `data/privatization_sales.json` (оновлює `scripts/update.py`; дані покупців не зберігаються)
- Положення про Управління майном комунальної власності міста (П-СУЯ/01) — розділи «Функції управління», «Положення»

## Архітектура
```
data/p3-01_listProzorroSales.csv ─┐
Prozorro.Продажі API ─────────────┼─ scripts/update.py → data/prozorro.json
PDF міста (договори, інвентар) ───┘                          │
                                  rules.json ─→ scripts/build.py → data/data.json, data-defects.csv
                                                             │
   web/template_v2.html + style_v2.css + Leaflet ─→ scripts/assemble.py → index.html (один файл)
```

## Запуск (≤ 15 хв на чистій машині)
1. **Подивитися:** відкрийте `index.html` у браузері. Сервер не потрібен; для підкладки карти потрібен інтернет.
2. **Оновити дані з API:** `pip install requests && python scripts/update.py`
3. **Змінити пороги:** відредагуйте `rules.json` і виконайте `python scripts/build.py && python scripts/assemble.py`, або змініть пороги в інтерфейсі (вкладка «Ознаки ризику»).
4. **Публічне демо:** GitHub Pages з кореня репозиторію (index.html) — https://golubmarkopoltava.github.io/RentMapPoltava/

Ключі API, паролі та токени не потрібні й у репозиторії відсутні.

## Публічна і внутрішня версії
Перемикач у шапці. **Публічна:** карта, каталог, агрегати, звірка. **Внутрішня:** додатково ознаки ризику, списки для аналізу, ознаки договорів.

## Відомі обмеження
- Ставки в переліку договорів наведені з ПДВ, у аукціонах — без ПДВ. Для порівняння ставки договорів поділено на 1,2.
- Зв’язування з документами міста виконано за нормалізованою адресою. 41 випадків потребують ручної перевірки.
- Ідентифікатори частини переможців приховані в самому Prozorro, тому повторні перемоги рахуються лише для відкритих кодів.
- Оцінка недоотриманого доходу — орієнтир (медіана аналогів), а не нарахування.
- Карта: підкладка Esri World Street Map з резервом OpenStreetMap France (перемикач шарів на карті); тайли OpenStreetMap і CARTO не віддаються локально відкритим файлам.
- 5 з 553 об’єктів не мають координат у Prozorro і на карту не ставляться.

## Етика
Сигнал — підстава для перевірки, а не доказ порушення. Імена фізичних осіб не показуються і не зберігаються: ІПН переможців-фізосіб у даних замінено хешем, в інтерфейсі вони позначені псевдонімами. Коди ЄДРПОУ юридичних осіб показано так, як у джерелі.

## Калькулятор «Скільки отримає громада: оренда чи приватизація»
Розділ «Аналітика», під калькулятором орендної плати. Для обраного об’єкта (або площі й району) порівнює накопичені надходження громади за 1–30 років:
- **оренда** — ставка з чинного договору об’єкта (÷ 1,2 без ПДВ) або медіана аналогів; параметри: місяці простою, частка до бюджету (100 % за замовчуванням — звіт Управління за І пів. 2026: 9 858 767 грн проти ≈ 9,74 млн грн суми ставок переліку без ПДВ за 6 міс.), річна індексація;
- **приватизація** — орієнтир ціни з 30 завершених аукціонів малої приватизації Управління на Prozorro.Продажі 2024–2026 (`data/privatization_sales.json`, оновлюється `scripts/update.py`): медіана ціни за м² 5 найближчих продажів (для об’єкта — за відстанню й площею, інакше — за площею в районі), або нижня / верхня чверть, або своя ціна; можна додати щорічні податки від нового власника;
- результат: різниця за горизонт, точка, коли оренда наздоганяє ціну продажу, графік накопичених надходжень, таблиця продажів-аналогів з посиланнями на аукціони.
Звірка: продажі травня 2026 (Шевченка 18, Новий Базар 18, Сортувальна 33) — 1 880 255 грн; у звіті Управління за І півріччя — 1 894 090 грн від приватизації.
